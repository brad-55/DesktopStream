# DesktopStream

日本語 | [English](README.en.md)

Windows PC の画面を、スマホや別の PC から見たり操作したりするソフトです。

- UAC(Windows の管理者確認)の画面やロック画面も、そのまま表示・操作できます。パソコンの前に行かなくても、管理者の確認を済ませて先に進めます
- 同じ Wi-Fi の中からも、外出先からも使えます(外出先からは、機器どうしが1対1で直接つなぎます)
- スマホに映している画面を、コメント付きでほかの人に見せることもできます

動作条件: Windows 10 / 11(64bit)

## 使ってみる

### 1. ダウンロード

**[最新版をダウンロード](https://github.com/brad-55/DesktopStream/releases/latest)**

| ファイル | どちらを選ぶか |
|---|---|
| `DesktopStream-...-setup.exe` | インストーラ。ふつうはこちらを選んでください |
| `DesktopStream-...-portable.zip` | 好きなフォルダに展開して使う版。インストーラを使いたくない場合に選んでください |

### 2. はじめる

[クイックガイド](https://brad-55.github.io/DesktopStream/quickstart.html)に、画面が映るまでの手順(5分ほど)をまとめています。
機能の詳しい説明と困ったときの対処は、[詳細ガイド](https://brad-55.github.io/DesktopStream/guide.html)にあります。

### スマホ側で開くページ

| 用途 | URL |
|---|---|
| 外出先から操作する | https://brad-55.github.io/DesktopStream/client.html |
| 配信を見る(視聴専用) | https://brad-55.github.io/DesktopStream/secondclient.html |

同じ Wi-Fi にいるときは、パソコン自身が提供する `https://パソコンのIP:8080` を開くこともできます(ルームID は要りません。初回は証明書の警告が出るので、「詳細設定」→「アクセスする」で進んでください)。

## ⚠️ このソフトは署名されていません

コードサイニング証明書を取得していないため、Windows SmartScreen やウイルス対策ソフトが警告を出します。
加えて、このソフトは「Windows の深い権限で常駐するサービス」「画面の取り込み」「キーボード・マウス操作の送信」「外部との通信」を組み合わせた作りです。これは遠隔操作型マルウェアと共通する特徴なので、警告が出やすくなります。

ダウンロードしたファイルが改ざんされていないことは、SHA256 で確かめられます。
正しい値は、各リリースのリリースノートに載せています。

```powershell
Get-FileHash .\DesktopStream-v0.8.1-setup.exe -Algorithm SHA256
```

上のコマンドの `DesktopStream-v0.8.1-setup.exe` は、実際にダウンロードしたファイル名に置き換えてください。

## 安全に使うために

- **ルームID は実質的なパスワードです。** 知っている人は誰でも、あなたの画面を見たり操作したりできます。人に見せないでください
- 初めて接続してきた端末は、パソコンの画面に出る確認で「はい」を押すまで接続できません
- 使い終わったら、Stop を押すか、パソコンのトレイから開くコンソールで切断してください
