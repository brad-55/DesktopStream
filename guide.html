これは何?

Desktop Stream は、Windows パソコンの画面と音を、スマホのブラウザへリアルタイムに配信するソフトです。 スマホ側はブラウザで開くだけで、アプリのインストールは要りません。スマホからパソコンのマウスを操作することもできます。

映像はパソコンとスマホの間で直接(P2P で)やり取りするので、外部のサーバーに保存されることはありません。

パソコン側は Windows サービスとして常駐し、パソコンを起動すると自動で待ち受けを始めます。毎回ソフトを立ち上げる必要はありません。 UAC の確認画面やロック画面も表示・操作できます。

2つの接続方法

おうちモード (LAN/VPN)どこでもモード (リモート)
使う場面同じWi-Fi内 / Tailscale利用時外出先などネットワークが違うとき
開き方https://パソコンのIP:8080(初回は証明書の警告を許可)配布ページを開く: https://brad-55.github.io/DesktopStream/client.html
ルームID不要必要(QRか文字で入力)
しくみパソコンに直接アクセスAyame Labo という無料の仲介サービスで互いを見つけ、映像は直接 P2P でやり取り
迷ったら、家の中では「おうちモード」、外からは「どこでもモード」を使ってください。

ルームIDについて

ルームIDは、「どこでもモード」で使う32文字の合言葉です。パソコンとスマホに同じルームIDを設定すると、互いを見つけて接続します。

表示する

パソコン側で、タスクトレイのアイコンを右クリックして「コンソールを開く」を選びます(アイコンのダブルクリックでも開きます)。 コンソールには、ルームID、その生成日時、QRコードが表示されます。

QRコードは2枚並んでいます。

QRコード中身
ルームID(リモート接続用)「どこでもモード」で使う合言葉。スマホ側に読み込ませます
接続URL(開く画面)スマホで開くページのURL。上のプルダウンで、外出先から使うページ(配布ページ)か、「おうちモード」で開く Tailscale / LAN / localhost のURLかを選びます

どの経路で繋がるかは環境によって違うため、プルダウンは自動では選びません。ふだん使っている経路(例: Tailscale)を選んでください。

作り直す(再生成)

コンソールまたはトレイメニューの「ルームID再生成」を押すと、新しいIDに変わります。IDを他人に知られた可能性があるときに使ってください。 再生成したら、スマホ側でもQRを読み直す必要があります。

ルームIDを知っている人は、あなたのパソコンの画面を見て操作できます。パスワードと同じように扱ってください。

画面は、スマホの言語に合わせて日本語か英語で表示されます。選ぶときは、設定タブの先頭の「言語 / Language」を使います。

画質と設定のコツ

コーデック(圧縮方式)の選びかた

名前特徴
QSV / NVENC / AMF / MFハードウェア方式。パソコンの負荷が軽く、処理が速いので、まずこれを試してください。Intel なら QSV か MF、NVIDIA なら NVENC、AMD なら AMF
H.264いちばん確実に映ります。迷ったらこれを選んでください。スマホでの画面録画もできます
H.265H.264より画質がよく、通信量も少なくて済みます。ただし映らないスマホがあり、画面録画は黒くなります
VP9H.264より画質がよく、画面録画もできます。スマホが対応していれば良い選択肢です
x264 / x265ソフトウェア方式。パソコンのCPUに負荷がかかります(比較・検証用)
AV1実験的な対応です。重く、映らないことが多いです

カクつくときの調整順

① bitrate を下げる(例: 1000→600)、② mtu を下げる(例: 1000→800)、③ buffer を増やす(例: 300)の順に試してください。 変更は、Start し直すと反映されます。

だんだん遅れてくるとき(ラグ)

長く使っていると、映像が実際より遅れてくることがあります。その場合は、上から順に試してください。

方法効果影響
⚡ラグ解消 ボタン溜まった遅れをその場で解消します映像が一瞬止まるだけです。再配信の視聴者は切れません
モードを「リアルタイム重視」にする遅れが溜まりにくくなります回線が不安定なときは、少しカクつきやすくなります
再接続ボタンいちばん確実です映像が数秒途切れ、再配信の視聴者も一度切れます

モードは設定タブで選べます。「動画視聴重視」はなめらかさを、「リアルタイム重視」は遅延の少なさを優先します。 リアルタイム重視では、遅れが大きくなると自動で追いつきます。

音と映像がずれるとき

🔊 音ズレ解消 ボタンを押すと、映像と音声の受信バッファの厚みを揃えてずれを直します。 統計表示に AVズレ:映像+600ms のように出ていれば、その分だけずれています。 リアルタイム重視モードでは、ずれが大きくなると自動で調整します。

遅れの内訳は、画面下の統計表示で確認できます(buf:=受信側で溜まっている遅れ、 rtt:=通信の往復時間、undec:=デコードの遅れ)。

マウス操作・入力方式

「入力」のプルダウンで、2つの方式を切り替えられます。

方式向いている場面動き
🖱 トラックパッドスマホ・タブレットなぞった量だけポインタが動く(初期設定)
⌨ 文字入力まとまった文章を打つとき入力欄に打ってから送信する

パソコンから操作する場合は、切り替えは要りません。設定の「物理マウス・キーボードは映像上で直接操作する」が 有効なら、映像の上でマウスを動かすだけで、パソコンのカーソルがその位置へ動きます。 指でのタッチはトラックパッドとして、マウスは直接操作として扱うので、両方を同時に使えます。

直接操作では、キーボードで打った文字が入力欄を経由せず、そのままパソコンへ入ります。日本語変換も使えます。 ただし Ctrl+W、Alt+Tab、Win キー単体は、ブラウザが先に受け取ってしまうため送れません。 これらは「キー送信」や専用ボタンから送ってください。

パッドをなぞるポインタを動かす(映像上の緑の輪が動く)
タップ左クリック
長押し(約0.65秒)右クリック

タスクマネージャーのような管理者として動くウィンドウや、UACの確認画面も操作できます。

ポインタの動きについて

指を滑らせている間も、パソコン側のカーソルが一緒に動きます。そのため、 ポインタを乗せただけで開くメニューや、ウィンドウの端でサイズ変更の矢印(↔ ↕)が出る動きも、そのまま使えます。

パソコンの前にいる人がマウスを動かした場合は、画面上のポインタがその位置へ移ります。 こちらから動かしている間は、こちらの操作が優先されます。

スクロールは、ポインタがある場所のウィンドウに対して行われます。スクロールしたいウィンドウの上にポインタを置いてください。

特別なキー操作

Windows が特別扱いするキーは、通常のキー送信では届きません。そのための専用ボタンがあります。

ボタンはたらき
Ctrl+Alt+Delセキュリティ画面を出します。ロック画面・ログイン画面で使います
画面ロックパソコンをロックします(Win+L と同じ)

キー送信で ctrl+alt+del や win+l と入力しても、ボタンと同じ処理になります。 送信できなかった場合は、その理由がログに表示されます。

再配信(サブ配信)

スマホで受信している画面を、ほかの人にもコメント付きで見せる機能です。

配信のしかた

「再配信」タブを開き、部屋数(見せたい人数。初期値は10)を確かめてから「再配信を開始」を押します。 表示されたURLかQRコードを、見てほしい人に送ってください。マイクの声も一緒に配信されます(「マイクON/ミュート」で切り替え)。

できること

映像の切り替えリモートデスクトップ / カメラ(背面) / 静止画 から選べます。配信中でも切り替えられ、静止画の切り取り枠の変更は配信中すぐに反映されます
PC音声「PC音声ON/OFF」で、パソコンの音(動画の音など)を配信に含められます。マイクとは別々に送るので、音量のバランスは見る人の側で調整できます
ミニプレビュー再配信タブの小さな窓で、実際に配信されている映像を確認できます
コメント視聴者の投稿は「コメント」タブに新しい順で表示され、全視聴者にも共有されます
視聴者数「視聴者: 〇/〇人」で、いまの人数がわかります
入退室のお知らせ視聴者の入退室は「コメント」タブに表示されます。視聴者ごとの履歴(名前・時刻・接続方法)は、「再配信」タブの下部に退室後も残ります

見る人(視聴者)側

送られたURLを開くと、空いている部屋に自動で入ります。名前と好きな色を選べば、コメントを書けます。 初めての人には名前の入力画面が出ますが、その間も席は確保されています(映像は名前を入れてから始まります)。 満員のときは入れません。

音声ボタンを押して「🔊 音声 ON」にすると、プレーヤー下の2本のスライダーで、 🎬動画(パソコンの音)と🎙配信者マイクの音量を別々に調整できます(最初はマイクの方が大きめです)。 配信タイトルは映像の下部に重ねて表示され、映像をタップすると表示と非表示が切り替わります。 「⛶ 全画面」で全画面表示になり、全画面中は右上の「✕ 全画面を終了」で戻れます。

視聴する画面は、視聴者のブラウザの言語に合わせて日本語か英語で表示されます。

人数が多いほど、配信するスマホの負荷と通信量(1人あたり約500kbps)が増えます。まずは2〜3人で試してください。 スマホをバックグラウンドにして配信が乱れても、画面に戻れば映像と音声を自動で取り直します。

便利な使いかた

ホーム画面に置く(アプリのように使う)

スマホのブラウザで「ホーム画面に追加」を選ぶと、アイコンから全画面で開けるようになります。 アドレスバーが消えるぶん、画面を広く使えます。

最近つないだ部屋の一覧(どこでもモード)

「ルームID入力」の画面に、最近つないだ部屋が新しい順に最大10件並びます。 「選ぶ」を押すと、その部屋に切り替わります。

各行には名前を付けられます。ルームIDはランダムな32文字なので、 「自宅PC」「仕事用ノート」のように名前を付けておくと、複数のパソコンを使い分けるときに区別できます。 要らなくなった行は「×」で消せます。ルームIDは長くて打ち直せないため、消す前に確認が出ます。

一覧では、ルームIDの途中を省いて表示します(aaaa1111…4444)。 ルームIDは実質的なパスワードなので、画面に全部を並べないためです。

設定の保存

画質(bitrate)、モード、P2P直結、入力方式、ポインタの形、再配信の設定などは、次に開いたときも前回のまま残っています。 設定は端末ごとに保存されるので、スマホとパソコンで別々の設定にできます。

コーデックと画面(モニタ)は、前回の選択がいまも選べる場合だけ元に戻します。 別のパソコンに繋いだときやモニタを外したときに、存在しない設定のまま Start して失敗するのを防ぐためです。

自動でのつなぎ直し

Start を押してから Stop を押すまでの間に接続が切れると、自動でつなぎ直します。 電波が悪くなったときや、スマホで他のアプリに切り替えて戻ったときが対象です。 つなぎ直しの様子は、「接続」タブのログに時刻付きで残ります。

つなぎ直しを止めたいときは、Stop を押してください。つなぎ直しの最中でも Stop は押せます。

他のアプリに切り替えている間の接続

ホーム画面に戻ったり他のアプリを開いたりしても、しばらくは接続を保ちます。 ただし、音声を「🔊 音声 ON」にしているときだけです。 鳴っている音が無いと、スマホのOSがブラウザを動かし続ける理由が無いと見なすためです。

拡大して見る

映像の上で2本指を広げると、1〜4倍まで拡大できます。最初に触った場所が拡大の中心になります。 拡大中にポインタを動かし、ポインタが画面の中央付近から外れると、表示範囲がポインタについて動きます。 中央付近で細かい操作をしている間は、表示範囲は動きません。左上の「1×に戻す」で元の大きさに戻ります。

ポインタの矢印は、狙いを付けやすいように、拡大しても大きさが変わりません。

全画面と文字入力

全画面中に「⌨」を押すと、映像の下に文字入力欄が出ます。映像はそのぶん少し小さくなります。 キーボードが出ている間はタブが隠れ、キーボードを閉じると戻ります。

通常の画面で文字入力にしたときも、キーボードが出ている間は、 映像と入力欄だけを残して、その間にあるボタン(音声・全画面・音量など)を一時的に隠します。 キーボードが画面の半分ほどを占めるため、ボタンを残すと映像と入力欄を同時に表示できないからです。 キーボードを閉じると、ボタンは戻ります。

困ったときは

映らない

  • コーデックを H.264 系に変えて、Start し直してください(いちばん確実です)
  • どこでもモードなら、スマホに設定したルームIDがパソコンのものと同じか確かめてください
  • スマホのログに pc failed と出る場合は、ネットワークの組み合わせによって直接接続できていない可能性があります。場所(回線)を変えると繋がることがあります

音が出ない

音声ボタンを押して「🔊 音声 ON」にしてください。ブラウザの仕様で、最初は必ず消音(OFF)で始まります。 再配信を見ていて片方の音だけ聞こえない場合は、プレーヤー下の「🎬動画」「🎙配信者マイク」のスライダーが 下がっていないか確かめてください。

カクカクする

「画質と設定のコツ」の調整順を試してください。統計(stats)の lost が増え続けるなら、回線に対して画質が高すぎます。

Startが押せない・「認証中…」のまま進まない

初めて接続する端末は、パソコンの画面に出る承認ダイアログで「はい」を押すまで操作できません。 承認すると端末が登録され、次回からは自動で認証されます。おうちモード(LAN)でも承認が必要です。

ログイン画面などで承認ダイアログを出せないときは、代わりにパソコン側のコンソール画面で、ワンタイムPINを使って承認します。 コンソールの「承認待ちの端末」に、接続してきた端末の名前とPINが並んで表示されます。 心当たりのある端末なら、そのPINを入力して「この PIN を許可」を押してください。

承認を求めるのは、同じネットワークに入れる人なら誰でも操作できてしまう状態を防ぐためです。

操作できないウィンドウがある

通常は、管理者として動くウィンドウも UAC の確認画面も操作できます。できない場合は、サービスが正しく動いているか確かめてください (タスクトレイのアイコンを右クリックして、「状態: 稼働中」と表示されるか)。

Ctrl+Alt+Del や 画面ロックが効かない

サービスを入れ直すと、必要な設定が自動で行われます。インストール用のバッチをもう一度実行してください。 それでも動かない場合は、ボタンを押したあとにクライアントのログに表示される理由を確かめてください。

パソコンを起動しても待ち受けが始まらない

コンソール画面またはトレイメニューで、「自動起動」が有効になっているか確かめてください。

コンソールに「旧方式のスタートアップ登録が残っています」という警告が出ている場合は、「削除する」を押してください。 古い登録が残っていると、サービスとは別にもう1つの DesktopStream が起動して、互いの動作を妨げます。

ルームIDを他人に知られたかもしれない

コンソール画面またはトレイメニューの「ルームID再生成」で新しいIDにして、スマホで読み直してください。 あわせて、コンソールの「登録済みの端末」から、心当たりのない端末を削除してください。 削除した端末は、接続中でもすぐに切断されます。

しばらく放置すると映像が止まる

画面の変化がまったく無い状態が続くと、パソコン側の画面の取り込みが止まることがあります。 動画や音声を再生している間は起こりません。 数秒で自動的に復帰する仕組みがありますが、マウスを動かすか ⚡ラグ解消 を押しても戻ります。

スマホから接続できない

次の順に確かめてください。

  • パソコン側のコンソール画面で、「受信の許可」が「登録済み」になっているか (未登録なら警告が出るので、ボタンで追加できます)
  • ブラウザに証明書の警告が出ていないか。初回は「詳細設定 → アクセスする」で許可する必要があります
  • コンソールの接続URLのQRで、実際に使っている経路(Tailscale / LAN など)を選んでから読み取っているか

調子が悪いときの切り替え設定(上級者向け)

次のフォルダに決まった名前の空ファイルを作ると、動作を変えられます。 作るには管理者権限が必要で、変えたあとはサービスを再起動する必要があります。

C:\ProgramData\DesktopStream\

ファイル名効果
capture_wgc画面の取り込み方法を変える。放置すると映像が止まる症状を避けるためのもの (同梱の set-capture-api.bat からも切り替えられます)
no_stall_watch映像が止まったときの自動復帰を止める
no_tls暗号化なし(http)で待ち受ける。証明書の警告を越えられないときに、原因を切り分けるためのもの。 ただし、IPアドレスで開いた場合はマイクとカメラが使えなくなります
worker_as_user従来の権限で動かす。UAC画面・ロック画面は映らなくなります
lang_en / lang_jaPC 側(トレイ・承認ダイアログ・コンソール)の表示言語を固定する。コンソールの「言語 / Language」からも選べます
