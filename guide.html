これは何?

Desktop Stream は、Windowsパソコンの画面と音を、スマホのブラウザにリアルタイム配信するソフトです。 スマホ側にアプリのインストールは不要で、ブラウザだけで見られます。スマホからパソコンのマウス操作もできます。

映像はパソコンとスマホの間で直接やり取り(P2P)されるので、映像が外部のサーバーに保存されることはありません。

パソコン側はWindowsサービスとして常駐します。パソコンを起動すると自動で待ち受けを始めるので、 毎回ソフトを立ち上げる必要はありません。UACの確認画面やロック画面も表示・操作できます。

2つの接続方法

おうちモード (LAN/VPN)どこでもモード (リモート)
使う場面同じWi-Fi内 / Tailscale利用時外出先などネットワークが違うとき
開き方https://パソコンのIP:8080(初回は証明書の警告を許可)配布ページを開く: https://brad-55.github.io/DesktopStream/client.html
ルームID不要必要(QRか文字で入力)
しくみパソコンに直接アクセスAyame Laboという無料の仲介サービスで出会い、映像は直接P2P
迷ったら: 家の中なら「おうちモード」、外からなら「どこでもモード」です。

ルームIDについて

ルームIDは「どこでもモード」で使う32文字の合言葉です。サーバーとスマホが同じルームIDを設定すると、お互いを見つけて接続します。

表示する

パソコン側のタスクトレイのアイコンを右クリック → 「コンソールを開く」(またはダブルクリック)で 設定画面が開きます。そこにID・生成日時・QRコードが表示されます。

QRは1枚ずつ表示され、上のプルダウンで切り替えられます。

選択肢中身
ルームID(リモート接続用)「どこでもモード」で使う合言葉。スマホ側に設定します
接続URL: …「おうちモード」で開くURL。Tailscale / LAN / localhost から実際に使う経路を選びます

どの経路で繋ぐかは環境によって違うため、自動では選びません。ふだん使っている方(例: Tailscale)を選んでください。

作り直す(再生成)

コンソールまたはトレイメニューの「ルームID再生成」で新しいIDになります。IDが他人に知られた(かもしれない)ときに使ってください。 再生成したら、スマホ側でもQRを読み直す必要があります。

ルームIDを知っている人は、あなたのパソコン画面を見て操作できます。パスワードと同じように扱ってください。

カクつくときの調整順

① bitrate を下げる(例: 1000→600) → ② mtu を下げる(例: 1000→800) → ③ buffer を増やす(例: 300)。 変更したら Start し直すと反映されます。

だんだん遅れてくるとき(ラグ)

長く使っていると映像が実際より遅れてくることがあります。その場合は次の順で試してください。

方法効果影響
⚡ラグ解消ボタン溜まった遅れをその場で解消します映像が一瞬止まるだけ。再配信の視聴者は切れません
モードをリアルタイム重視にそもそも遅れが溜まりにくくなります回線が不安定なときは少しカクつきやすくなります
再接続ボタンいちばん確実映像が数秒途切れ、再配信の視聴者も一度切れます

モードは設定タブで選べます。動画視聴重視はなめらかさを優先、リアルタイム重視は 遅延の少なさを優先します。リアルタイム重視では遅れが大きくなると自動で追いつきます。

音と映像がずれるとき

🔊 音ズレ解消 ボタンを押すと、映像と音声の受信バッファの厚みを揃えて直します。 統計表示に AVズレ:映像+600ms のように出ていれば、その分ずれています。

リアルタイム重視モードでは、ずれが大きくなると自動で調整します。

遅れの内訳は画面下の統計表示で確認できます(buf:=受信側で溜まっている遅れ、 rtt:=通信の往復時間、undec:=デコードの遅れ)。

マウス操作・入力方式

「入力」のプルダウンで3つの方式を切り替えられます。

方式向いている場面動き
🖱 トラックパッドスマホ・タブレットなぞった量だけポインタが動く(初期設定)
⌨ 文字入力まとまった文章を打つとき入力欄に打ってから送信

パソコンから操作する場合は切り替え不要です。 設定の「物理マウス・キーボードは映像上で直接操作する」が 有効なら、映像の上でマウスを動かすだけでパソコンのカーソルがその位置に動きます。 指でのタッチはトラックパッド、マウスは直接操作、という住み分けで同時に使えます。

直接操作モードでは、キーボードで打った文字がそのままパソコンへ入ります(入力欄を経由しません)。 日本語変換もそのまま使えます。ただし Ctrl+W や Alt+Tab、Winキー単体は ブラウザ側が先に受け取ってしまうため送れません。その場合は「キー送信」や専用ボタンを使ってください。

操作動き
パッドをなぞるポインタ移動(映像上の緑の輪が動く)
タップ左クリック
長押し(0.5秒)右クリック
2本指で上下になぞるスクロール(指の動きにコンテンツが追従)
映像右のつまみを上下にドラッグスクロール(スクロールバーの操作感。下へ動かすと画面が下へ)
音量−/音量＋/消音サーバーPC本体の音量を操作
全画面中映像を直接なぞって操作
タスクマネージャーやUACの確認画面などの管理者ウィンドウも操作できます。

ポインタの動きについて

指を滑らせるだけでもパソコン側のカーソルが一緒に動きます。そのため、 ボタンに乗せるだけで反応するメニューや、ウィンドウの端でサイズ変更の矢印(↔ ↕)が出る動きも そのまま使えます。

パソコンの前にいる人がマウスを動かした場合は、その位置に画面上のポインタが追いつきます。 逆にこちらから動かしているときは、こちらが優先されます。

スクロールはポインタがある場所に効きます。スクロールしたいウィンドウの上にポインタを置いてください。

特別なキー操作

Windowsが特別扱いするキーは、通常のキー送信では届きません。専用のボタンを用意しています。

ボタンはたらき
Ctrl+Alt+Delセキュリティ画面を出します。ロック画面・ログイン画面で使います
画面ロックパソコンをロックします(Win+L と同じ)

キー送信で ctrl+alt+del や win+l と入力しても、自動的に同じ処理になります。 送信できなかった場合はログに理由が表示されます。

再配信(サブ配信)

スマホで受信している画面を、ほかの人にもコメント付きで見せられる機能です。

配信のしかた

「再配信」タブ → 部屋数(見せたい人数、初期値10)を確認 → 「再配信を開始」。 表示されたURLかQRコードを見たい人に送るだけです。マイクの声も一緒に配信されます(「マイクON/ミュート」で切替)。

できること

映像の切替リモートデスクトップ / カメラ(背面) / 静止画。配信中でも切り替えられます(静止画の切り取り枠は配信中すぐ反映)
PC音声「PC音声ON/OFF」でパソコンの音(動画の音など)を配信に含められます。マイクとは別々に送られ、音量バランスは見る人の側で調整できます
ミニプレビュー再配信タブの小さな窓で、実際に配信されている映像を確認できます
コメント視聴者の投稿が「コメント」タブに表示され、全視聴者にも共有されます(新しいものが上)
視聴者数「視聴者: 〇/〇人」で現在の人数がわかります
入退室のお知らせ視聴者が入ったり抜けたりすると「コメント」タブに表示されます。「再配信」タブの下部に視聴者ごとの履歴(名前・時刻・接続方法)が退室後も残ります

見る人(視聴者)側

送られたURLを開くだけです。自動で空いている部屋に入り、名前と好きな色を選んでコメントできます。 初めての人は名前の入力画面が出ますが、その間も席は先に確保されます(映像は名前を入れると始まります)。 満員のときは入れません。音声ボタンを押して「🔊 音声 ON」にした後は、プレーヤー下の2本のスライダーで 🎬動画(PCの音)と🎙配信者マイクの音量を別々に調整できます(最初はマイクの方が大きめ)。 配信タイトルは映像の下部に重なって表示され、映像をタップすると消したり出したりできます。 「⛶ 全画面」で全画面表示、全画面中は右上の「✕ 全画面を終了」で戻れます。

人数が多いほどスマホの負荷と通信量(1人あたり約500kbps)が増えます。まずは2〜3人で試すのがおすすめです。 スマホをバックグラウンドにして配信が乱れても、画面に戻れば自動で映像・音声を取り直します。

便利な使いかた

ホーム画面に置く(アプリのように使う)

スマホのブラウザで「ホーム画面に追加」を選ぶと、アイコンから全画面で開けるようになります。 アドレスバーが消えるぶん画面を広く使えます。

よく使う部屋を覚えておく(どこでもモード)

「ルームID入力」の画面に最近つないだ部屋が新しい順で並びます(最大10件)。 「選ぶ」を押すだけで切り替えられます。

各行に好きな名前を付けられます。ルームIDはランダムな32文字なので、 「自宅PC」「仕事用ノート」のように書いておくと、複数のパソコンを使い分けるときに迷いません。 要らなくなった行は「×」で消せます(確認が出ます。ルームIDは長くて打ち直せないため)。

ルームIDは一覧では途中を省いて表示します(aaaa1111…4444)。 ルームIDは実質的なパスワードなので、画面に全部並べないためです。

設定は覚えています

画質(bitrate)・モード・P2P直結・入力方式・ポインタの形・再配信の設定などは、 次に開いたときも前回のままです。端末ごとに覚えるので、スマホとPCで別々の設定にできます。

コーデックと画面(モニタ)だけは、前回の選択が今も使える場合だけ戻します。 別のパソコンに繋いだときや、モニタを外したときに、存在しない設定のままStartして失敗しないようにするためです。

切れても自動でつなぎ直します

Startを押してからStopを押すまでの間だけ、接続が切れると自動でつなぎ直します。 電波が悪くなったとき、スマホを他のアプリに切り替えて戻ったときなどが対象です。 つなぎ直しの様子は「接続」タブのログに時刻付きで残ります。

つなぎ直しを止めたいときは Stop を押してください。 試行中でも Stop は押せるようにしてあります。

他のアプリに切り替えても続ける

ホーム画面に戻ったり他のアプリを開いたりしても、しばらく接続を保ちます。 音声を「🔊 音声 ON」にしていないと効きません — 鳴っている音が無いと、 OSから見て「維持すべきもの」が無いためです。

拡大して見る

映像の上で2本指を広げると1〜4倍まで拡大できます。最初に触った場所が中心になります。 拡大中はポインタを動かすと、ポインタが画面の中央付近から外れたときに表示範囲がついてきます。 細かい操作をしている間は画面が揺れません。左上の「1×に戻す」で元に戻ります。

ポインタの矢印は拡大しても大きさが変わりません(狙いが付けやすいように)。

全画面と文字入力

全画面中に「⌨」を押すと、映像の下に文字入力欄が出ます。映像はそのぶん少し小さくなります。 キーボードが出ている間はタブが隠れますが、キーボードを閉じれば戻ります。

通常の画面で文字入力にしたときも、キーボードが出ている間は 映像と入力欄だけを残して、間のボタン(音声・全画面・音量など)を一時的に隠します。 キーボードで画面が狭くなるため、そうしないと映像と入力欄が同時に見えないからです。 キーボードを閉じればボタンは戻ります。

困ったときは

映らない

・コーデックを H.264系 に変えて Start し直す(いちばん確実)
・どこでもモードならルームIDが正しいか確認(サーバーと同じか)
・スマホのログに pc failed と出る場合、ネットワークの相性で直接接続できないことがあります。場所(回線)を変えると繋がることがあります

音が出ない

音声ボタンを押して「🔊 音声 ON」にしてください。ブラウザの仕様で、最初は必ず消音(OFF)で始まります。 再配信の視聴で片方の音だけ聞こえない場合は、プレーヤー下の「🎬動画」「🎙配信者マイク」のスライダーが 下がっていないか確認してください。

カクカクする

「画質と設定のコツ」の調整順を試してください。統計(stats)の lost が増え続けるなら回線に対して画質が高すぎます。

Startが押せない・「認証中…」のまま進まない

初回接続時はサーバーPCの画面に承認ダイアログが出ます。「はい」を押すとこの端末が登録され、 次回からは自動で認証されます。おうちモード(LAN)でも承認が必要です。

パソコンの前にいないときは、パソコン側のコンソール画面でワンタイムPINによる承認もできます。 接続すると画面にPINが表示されるので、それを入力してください。

承認前は操作できません。これは、同じネットワークに入れる人なら誰でも操作できてしまう状態を防ぐためです。

操作できないウィンドウがある

通常は管理者ウィンドウもUACの確認画面も操作できます。できない場合は、サービスが正しく動いているか確認してください (タスクトレイのアイコンを右クリック →「状態: 稼働中」と表示されているか)。

Ctrl+Alt+Del や 画面ロックが効かない

サービスを入れ直すと必要な設定が自動で行われます。インストール用バッチをもう一度実行してください。 それでも効かない場合は、ボタンを押したあとにクライアントのログに表示される理由を確認してください。

パソコンを起動しても待ち受けが始まらない

コンソール画面またはトレイメニューで「自動起動」が有効になっているか確認してください。

また、コンソールに「旧方式のスタートアップ登録が残っています」という警告が出ている場合は、 「削除する」を押してください。古い設定が残っていると、サービスとは別のソフトが同時に起動して お互いの邪魔をします。

ルームIDを他人に知られたかも

コンソール画面またはトレイメニューの「ルームID再生成」で新しいIDにして、スマホで読み直してください。 あわせて、コンソールの「登録済みの端末」から心当たりのない端末を削除してください (削除すると、その端末は接続中でもすぐ切断されます)。

しばらく放置すると映像が止まる

画面の変化がまったく無い状態が続くと、取り込みが止まることがあります(パソコン側の仕組みの制約です)。 マウスを動かすか、⚡ラグ解消 を押すと戻ります。数秒で自動的に復帰する仕組みも入っています。

動画や音声を再生している間は起こりません。

スマホから接続できない

次の順に確認してください。

  • パソコン側のコンソール画面で「受信の許可」が「登録済み」になっているか (未登録なら警告が出るので、ボタンで追加できます)
  • ブラウザに証明書の警告が出ていないか。初回は「詳細設定 → アクセスする」で許可が必要です
  • コンソールのQRから、実際に使っている経路(Tailscale / LAN など)を選んで読み取っているか

調子が悪いときの切り替え設定(上級者向け)

次のフォルダに、決まった名前の空ファイルを作ると動作を変えられます。 作成には管理者権限が必要で、変更後はサービスの再起動が必要です。

C:\ProgramData\DesktopStream\

ファイル名効果
capture_wgc画面の取り込み方法を変える。放置すると映像が止まる症状の回避用 (同梱の set-capture-api.bat からも切り替えられます)
no_stall_watch映像が止まったときの自動復帰を止める
no_tls暗号化なし(http)で待ち受ける。証明書の警告が越えられないときの切り分け用。 ただしIPでのアクセスではマイク・カメラが使えなくなります
worker_as_user従来の権限で動かす。UAC画面・ロック画面は映らなくなります

メモ帳で作ると no_tls.txt のように拡張子が付きますが、そのままでも認識します。

うまくいかないときの記録の場所

動作の記録(ログ)は次の場所にあります。メモ帳で開けます。

C:\ProgramData\DesktopStream\logs\ (service.log = サービス本体、worker.log = 配信の本体)
